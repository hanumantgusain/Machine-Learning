# Machine Learning

A collection of reproducible machine-learning projects demonstrating
data preparation, feature engineering, model development, evaluation
and interpretation using Python and scikit-learn.

The repository covers fundamental supervised and unsupervised learning
problems, including classification, regression and clustering. Each
project follows a structured workflow with exploratory analysis,
preprocessing pipelines, baseline models, cross-validation, final
evaluation and error analysis.

This work supports my progression from MSc Data Science toward AI
engineering and research in reliable multimodal AI systems.
